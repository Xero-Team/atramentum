# 02 Shelf and categories

> Goal: **learn to arrange and file your content** — create categories, drag cards into them, and delete or move things out again.

---

## 2.1 How the shelf is laid out

The shelf groups courses by **category**: one block per category, with a count beside its title. Anything not filed anywhere lands in an **Uncategorised** group at the bottom (shown only when it has something in it).

Each card carries:

- **A seal** — a cinnabar 「C」 for md courses (the first character of the title), an ink 「B」 for books.
- **Delete** (top right, on hover): built-in courses have none — they ship with the site.
- **Move out** (top left, on hover): only on cards that are filed somewhere; takes the card back to Uncategorised in one tap.
- **A source badge**: Built in / Imported / AI written.

## 2.2 Every category is yours

Nothing is pre-set. Tap **＋ New category** at the bottom of the shelf, type a name (Study / Textbooks / Fiction), and press Enter.

- Empty categories are shown too, so you can make the group before you have something to drop into it.
- Deleting a category deletes only the grouping. Its contents return to Uncategorised — nothing is lost.

## 2.3 Filing by drag and drop

**Drag a card onto** the category you want (the block gains a cinnabar outline) and let go:

```
┌─ Study ─────────────┐
│  ┌────────┐  ┌────┐ │
│  │ card A │  │ B  │ │   ← drop it here
│  └────────┘  └────┘ │
└─────────────────────┘
```

While dragging, a cover-style ghost (seal plus title) replaces the browser's default URL drag image.
