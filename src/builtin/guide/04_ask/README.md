# 04 问 AI

> 本节目标:**用四个入口把 AI 变成陪读者**——划词发问、自由提问、改写本节,以及划词标注与笔记;并看懂「工作流程」时间线。

---

## 4.1 划词:问 或 标

在正文里**划选一段内容**,选区右下角会浮出两枚小印:

```
… 段落文字 【用户划选】进程控制块 【后文】…
      ┌────┬────┐
      │ 问 │ 标 │  ← 左「问 AI」，右「只上墨」
      └────┴────┘
```

| 按钮 | 做什么 |
|------|--------|
| **问** | 把「选区 + 所在节标题 + 前后文」打包发给 AI,并在正文里留下一道高亮 |
| **标** | 不问 AI,只把这段**高亮**下来并弹出笔记卡,适合自己划重点 |

两条路都会在正文里留下痕迹:点击那道高亮/下划线,就能重新看到当时问过什么、写了什么。

**按完按钮,选区会自动收起。** 这是刻意的:浏览器的选区是朱红底白字的不透明块,不收起来会一直
盖在标注上——既像是「划词状态撤不掉」,也让高亮与下划线的差别完全看不出来(切了样式却像被锁死)。

**按错了可以退。** 「标」下一条后,屏幕下方会出现「已标注「…」·撤销」,几秒内点「撤销」就把它撤掉。
没配 AI 时点「问」不会留下任何东西——标注、记录、请求一概不发生。

每次「问」都会**开一轮新会话**(旧对话清空,避免上下文串味),历史记录见 4.5。

## 4.2 自由提问 + Agent 检索

在面板底部输入框直接提问。问 AI 不是普通聊天——它是**带工具的 agent**:

1. AI 可调用三只只读工具:`list_course_files`(浏览目录)、`read_course_file`(读文件)、`search_course`(全文检索)。
2. 需要跨节/跨文件信息时,它会先检索再精读,一轮最多 8 次工具调用。
3. 全部过程在「**工 作 流 程**」时间线里展示:每一步 ◐ 进行中 / ✓ 完成 / ✕ 失败,点「详情」可看工具原始输出。

首条自由提问可勾选「附上本节全文」,让 AI 不查直接答;后续追问由 agent 按需自查。

## 4.3 改写本节

切到「改写本节」模式,输入修改要求(如「精简本节」「补一个例子」):

- AI 输出改写后的完整正文(流式)。
- **满意再点「应用到本节」**——不满意可继续提要求再改。
- 应用后正文立即刷新;内置课件会自动另存为副本再应用。

## 4.4 标注:高亮、下划线与笔记

划过的每一段都是**一条标注**,它跟着**这本书**存下来:

- **两种样式**:高亮(淡朱底)与下划线,在标注卡里一键切换,即时生效。
- **笔记注释**:点高亮弹出标注卡,下方就是笔记框,**失焦即存**——写完点别处不会丢。
- **怎么定位**:标注记的是「字符偏移 + 原文」。正文被 AI 改写后偏移可能失准,此时会按原文重新找一遍;
  实在找不到(那段文字被删了)才会失效。
- **在哪儿看全**:点阅读器 header 或面板头部的「历史」,左侧滑出抽屉,「划词标注」一节列出全书标注;
  点一条即跳到所在课时并打开卡片。
- **标错了**:标完几秒内屏幕下方有「撤销」;错过了就点开标注卡,里面也有「删除标注」。
- **卡片挡住正文了**:抓住卡片顶部那条(左边有个 ⠿)拖走即可。它本来就会自己躲——
  下方放不下时自动翻到划词上方,所以笔记框不会掉到屏幕外。

标注不是装饰——它是你在这本书里留下的**唯一一份自己的东西**,所以它会被导出、会被导入(见 06_io)。

## 4.5 问答历史:保存、复现、删除

点「历史」(阅读器 header 或 AI 面板头部都行),列表从**屏幕左侧滑出**,盖在目录树之上:

```
┌───────────┬──────────────┬────────┐
│ 历史（滑出）│     正 文     │ AI面板 │
│ · 划词标注 │              │        │
│ · 问答历史 │              │        │
└───────────┴──────────────┴────────┘
```

**每一轮问答都自动存下来**,不需要手动保存:

| 操作 | 效果 |
|------|------|
| 点某一条 | 右侧面板里**复现整段对话**(划选原文、工作流程、回答原样回来) |
| 复现后继续问 | 直接追问,新的一轮追加到同一段对话里,历史随之更新 |
| 删除 | 删掉单条;底部还有「清空本书问答」 |

复现是**读本地记录**,不会重新请求 AI,所以随便点、零消耗。

> 为什么值得留着?AI 回答过一次的东西,三天后往往还想再看一眼——
> 而当时问它的那个上下文(划了哪句、第几节)已经不在屏幕上了。

## 4.6 追问

同一轮会话里的追问会带上前几轮问答(短文本形式),不用重复背景。复现历史后继续问,也是同一条会话。

6. 在历史里点开三个月前的一段问答,会重新消耗额度吗?为什么?
